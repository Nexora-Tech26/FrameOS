# FrameOS update and compatibility roadmap
Part 4: Kiwi Menu, compatible extensions, right-hand app grid. Never bypass GNOME shell-version validation. Open Bar remains conditional on upstream support; preserve the native panel if unavailable.
Part 6: package FrameOS components as debs, create a signed APT repository and connect GNOME Software through PackageKit. Keep Ubuntu repositories for security and kernel updates. Flatpak is for applications, not OS upgrades. Use a dedicated signing key and CI secret; do not publish unsigned repositories. Hosting and key provisioning remain pending.
Part 13: Frame Update, update history, Stable/Beta/Nightly channels, safe recovery and tested upgrade/rollback strategy.
Part 14: Frame Windows Bridge (Wine, Winetricks, isolated prefixes, EXE/MSI associations, compatibility guidance) and Universal Install. Windows app support is not universal; do not run unknown executables automatically.
