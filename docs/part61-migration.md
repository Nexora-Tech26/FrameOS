# Part 6.1: installer baseline
First validation milestone uses the signed upstream Noble desktop ISO and retains all original installer layers, boot components and installer UI. Only GRUB menu text and media marker are changed. This baseline installs Ubuntu, NOT the finished FrameOS desktop; do not distribute as a finished release. Next milestone must integrate the FrameOS target and live layers, Orchis Grey GTK3/GTK4 resources, Fluent, and compatible Open Bar Trilands, and rebuild the installer frontend branding. The previous custom installer remains in history and is no longer the active CI build. No VM test yet.
