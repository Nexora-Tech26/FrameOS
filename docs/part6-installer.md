# Part 6 installer preview
Calamares with distribution branding, native locale/keyboard/partition/users/summary pages and separate offline target squashfs. Target omits Casper and installer. GRUB BIOS/UEFI binaries included. Preview has no verified Secure Boot chain, no MOK setup, no validated dual boot or encryption. Do not use on a disk containing important data until VM tests succeed. Separate target and live images increase ISO size. GNOME Software remains unchanged; signed FrameOS APT repository requires key provisioning and hosting, not implemented here. Plymouth/GDM customization and installer Qt styling beyond branding remain pending.
