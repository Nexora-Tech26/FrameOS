# Native installer wizard
GTK4/libadwaita sequential pages: welcome, language and location, keyboard, automatic storage, account, review, installation and finish. Disk list includes ineligible devices with labels and refresh, selects first eligible blank disk by default, no disk writes before review confirmation. The same restricted UEFI backend is retained. Progress represents installation stages, not measured percentage. Dual boot, manual partitioning, encryption, legacy BIOS and Secure Boot are not supported. Regional defaults use live locale/timezone; no IP geolocation. Test only on disposable blank virtual disks. No runtime test yet. Ubuntu LTS migration remains separate.
