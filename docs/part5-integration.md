# Part 5 native GNOME desktop
Global Menu and Frame Integration are no longer installed or enabled. Retain native GNOME clock, calendar, notifications and Quick Settings. Use original Open Bar with Trilands when an upstream release explicitly supports the installed GNOME version; otherwise retain native panel. Keep heavy effects optional and animations disabled by default for stability. User Themes remains optional to avoid replacing the native Shell stylesheet while diagnosing clock issues. GTK Orchis, Kiwi Menu and right-side app grid remain. No runtime validation yet; full Open Bar GNOME 51 support remains an upstream dependency. Native power profiles require a supported backend and hardware; no new backend installed in this change.
