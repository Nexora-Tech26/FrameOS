# Part 5 integration preview
Native GNOME clock/calendar and quick settings retained. Frame Integration adds active app name, contextual fallback File/Edit/View/Help menus and a lightweight settings launcher. These are not exported application-specific global menus. Full DBus menu/action export and a dedicated custom Control Center remain pending. Open Bar upstream metadata supports 45–49 only; GNOME 51 uses a lightweight CSS island fallback instead, without spoofing version support. Heavy effects and Just Perfection remain installed when compatible but opt-in by default; VM detection additionally disables heavy effects. No claim of runtime validation until VM testing.
